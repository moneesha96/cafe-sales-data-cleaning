# cafe-sales-data-cleaning
Beginner data cleaning project using Excel to clean, validate, and prepare a messy Cafe sales dataset for analysis 

Methods:
Cleaned a messy café sales dataset to improve its quality and prepare it for future analysis. Identified and handled missing values, duplicate records, inconsistent entries and incorrect data types, and standardised the data to create a clean and reliable dataset.

Outcome:
Produced a cleaned and structured dataset suitable for further analysis and visualisation. The project demonstrates practical skills in data quality assessment, data cleaning and data preparation.
